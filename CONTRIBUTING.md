## 📖 Introducción

Tu contribución es clave para el crecimiento de KiddieOS.  
Puedes participar desde distintos niveles: desde reportar errores hasta desarrollar nuevas funcionalidades.

📌 Usa tu criterio y si tienes ideas para mejorar este documento, puedes enviar un Pull Request.

---

## 🚀 Cómo contribuir

### 🐛 Reportar bugs

Los errores se gestionan mediante **Issues**.

Al crear uno, incluye:

- 🏷️ Título claro y descriptivo  
- 🔁 Pasos para reproducir el problema  
- 📷 Evidencia (capturas, logs si es posible)  
- 🎯 Resultado esperado vs resultado actual  

👉 Issues:  
https://github.com/isairey/SistemaOperativo-OS/issues

---

### 💡 Sugerir mejoras

Las mejoras también se gestionan como **Issues**.

Incluye:

- 📌 Descripción clara de la mejora  
- ⚙️ Comportamiento actual  
- 🚀 Beneficio esperado  
- 📊 Justificación de utilidad  

💡 Consejo:  
Las mejores sugerencias son **específicas, viables y alineadas al estado actual del sistema**.
